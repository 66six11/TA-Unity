# 三维体积烟雾流体

完整讲解图、推导、资源表和验证说明见 [技术文档](../../Docs/VolumeSmoke3D/TechnicalGuide.md)。

场景：`Assets/VolumeSmoke3D/VolumeSmoke3DDemo.unity`。新增独立体积光场景：`Assets/VolumeSmoke3D/VolumeSmokeLightingDemo.unity`。

[体积光与中间视图操作说明](../../Docs/VolumeSmoke3D/LightingGuide.md) 包含实际预览、衰减公式和验证结果。

当前版本已经重构为 **屏幕捕获动态模型表面 → 重建三维发射源 → 世界空间三维烟雾模拟**。之前的二维屏幕网格版本完整保留在 `Assets/ScreenGridSmoke/ScreenGridSmokeDemo.unity`，两个示例可分别运行。

屏幕空间用于获取动态发射位置、法线、表面速度和近似障碍；烟雾速度、压力、密度仍保存在固定世界空间体积中。此例不是摄像机对齐/Froxel 三维求解器。

## 自由视角

点击 Game 窗口后：

- 按住 **鼠标右键**：鼠标转向。
- 右键按住时，**W/A/S/D**：前后左右；**Q/E**：向下/向上。
- **Shift**：加速；右键按住时滚轮调整移动速度。
- 松开右键恢复鼠标，可操作参数面板；**Esc** 释放鼠标。
- 面板上的 **Orbit -30 / +30** 也可绕烟雾体积观察。
- **Animate moving source** 让源模型平移、旋转，观察新烟跟随模型、旧烟留在世界空间形成拖尾。
- **Mask / Depth / Normals / Motion** 直接查看模型的屏幕捕获数据，Smoke 返回体积烟雾。

摄像机可进入体积内部。旋转、平移和改变画面尺寸不会重置模拟；只有明确点击 Reset、重建模拟或组件生命周期变化才清空状态。`VolumeSmokeFreeCamera` 使用本项目已安装的 Unity Input System。

## 三维模拟

`VolumeSmokeSimulation` 在固定的、世界空间轴对齐立方体中维护：

- 3D 速度场和密度场，双缓冲。
- 3D 压力场，默认 32 次 Jacobi 迭代。
- 3D 旋度、投影前后散度。场景光照由渲染阶段单独计算。

每步执行速度平流、发射/浮力/旋转外力、三维涡量约束、散度与压力求解、压力梯度投影、密度平流。散度和压力梯度采用匹配的前后差分，与七点 Laplacian 一致。有限次数的压力迭代仅近似消除散度。

默认分辨率 **64×64×64**，模拟盒边长 **6 世界单位**。可在退出 Play 后调整 Resolution 并重新初始化，96³/128³ 会增加细节与计算、存储开销。

## 模型如何发烟

每帧由指定的 **Source Camera**（未设置时使用 Camera.main）单独绘制源模型：

1. 前表面 Pass 使用深度测试输出设备深度、世界法线/Mask、世界表面运动速度三张目标。
2. 背表面 Pass 记录每像素最远的背面观察空间深度。
3. Compute Shader 将每个三维格子投影到捕获纹理，读取深度，再用捕获时的逆 GPU VP 矩阵重建对应表面点。坐标包含 RenderTexture Y 翻转和设备深度约定处理。
4. 表面沿法线偏移约 0.75 个体素，在 `Source Band Cells` 半径内生成平滑的体积发射权重。每个体素独立收集一个样本，不采用逐像素累加，因此不会因为捕获分辨率翻倍而使发烟量成倍增加。
5. 模型当前矩阵与上一次捕获矩阵在顶点处计算刚体表面速度，包含平移和旋转；映射到源速度体积后由 `Inherit Source Motion` 控制继承强度，`Max Source Speed` 限制突然跳变。
6. 前后深度区间在三维网格中重建近似障碍，参与压力边界与密度裁剪。源模型移动后这些区域重新生成，旧烟雾状态不被整体清空或平移。

运行时不读取 CPU 顶点，不要求源网格启用 Read/Write，模型平移、旋转和普通缩放都会反映到捕获中。当前使用 MeshFilter，未接入 SkinnedMeshRenderer、BlendShape 或原材质中的自定义顶点变形。

**只有捕获相机朝向的最前层表面会发烟。** 源捕获只绘制目标模型本身，不读取其他场景物体的遮挡；被场景物体挡住的目标仍可能注入烟雾，最终画面再按场景深度遮挡。相机看不到/模型离开捕获视野的区域不再产生新发射，已有烟雾继续演化。若捕获相机停止渲染，过期的源数据会被清空，避免在旧位置持续发烟。

**前后深度不是完整的三维碰撞模型。** 每像素只有一个前后区间，凹形、多层相交几何可能错误填充中间空隙；开放网格没有有效背面时仍可发烟，但不会得到可靠的内部障碍。它是动态、可视范围内的近似，不能替代 SDF 或完整体素碰撞。

运动速度继承作用于发射带，障碍压力边界仍采用零法向速度近似，没有实现完整的移动壁面流体耦合。

换模型时把 MeshFilter 拖入 Source，保留原 Renderer。模型在当前模拟盒内移动无需重建；离开这个固定盒子后不再注入盒外烟雾。移动模拟盒或更换网格分辨率、盒子大小，需要执行 **Rebuild volume**，这会清空当前烟雾；本次没有加入移动模拟域及历史搬移。

当前更新顺序为：Update 使用上一帧的重建源推进一次模拟，随后 URP 捕获当前模型并重建下一步源，最后渲染烟雾。这样不需要同步回读，但动态源约有一帧延迟。多个观察摄像机共享同一三维状态；只有 Source Camera 更新源数据。

## 体积渲染

`VolumeSmokeFeature` 在不透明场景之后，通过全屏射线与世界空间盒子求交，沿射线读取三维密度并从前向后累积散射和透射率。读取场景深度裁剪射线终点，因此物体能遮挡后方烟雾，前方烟雾也能覆盖物体。

场景灯光接入临时 RGBA16F 光照体积：支持最多 8 盏方向光、点光、聚光灯，计算距离/范围/聚光锥衰减、烟雾沿光路的透射率和 HG 相函数。默认每灯每体素 12 次密度采样。暂停模拟后移动灯光也会更新。当前不读取实体物体阴影贴图。默认 128 个射线采样，较低分辨率可能显得柔软、扩散；这不是屏幕贴图随相机旋转的结果。

独立的 `Generated/VolumeRenderer.asset` 追加到当前 URP Asset Renderer List，保留原默认 Renderer 和已有的屏幕空间示例 Renderer。示例摄像机选择这个 Renderer，并通过 `VolumeSmokeCamera` 引用世界模拟组件。多个摄像机可以观察同一个模拟对象，不应重复推进模拟。

## 资源与性能

本例适用于 Unity 6000.5.7f1、URP 17.5、RenderGraph、桌面 DX12、普通透视摄像机。相机关闭 MSAA。未适配 XR、相机堆叠、正交摄像机和动态分辨率。

3D 状态纹理由模拟组件拥有，初始化创建，禁用/销毁时释放；另有动态障碍、源法线/权重、源速度三张持久体积纹理。RenderGraph 导入它们，声明源重建的写入与合成的读取；屏幕捕获纹理和深度附件为 RenderGraph 临时资源。模拟 Compute Dispatch 与渲染使用同一 GPU 图形队列，不启用异步计算。

64³ 网格的十二张持久体积纹理约 **23 MiB**，另有每观察相机约 **2 MiB** 的临时光照体积，不含相机目标和屏幕捕获临时目标。默认捕获高度 256，宽度随视口宽高比变化。网格边长从 64 增加到 96 时，体素数量为 3.375 倍；射线步进和压力迭代也各自增加开销。应通过目标设备 Profiler 测量性能。本例没有空体素跳跃、稀疏网格、降分辨率体积重建或多重网格压力求解。

时间步限制为最多 1/30 秒，低帧率时模拟会减慢。外力、涡量和烟雾颜色为视觉参数，并非经过物理量纲标定的燃烧/热力学系统。未实现地面模拟碰撞、真实烟雾投影和透明物体的完整排序。

## 验证

菜单 **Tools > TA > Volume Smoke 3D > Build and Verify Demo** 实际执行 240 步 GPU 模拟并验证：

- 密度有限、非负，分布于多个 Z 深度切片，重建障碍内为零。
- 压力投影降低三维散度 RMS。
- 同一暂停状态从正面、侧面、背面渲染后，所有密度体素逐个相等。
- 改变画面尺寸不重建/清空世界模拟。
- 平移和旋转模型使源权重中心跟随，表面运动速度非零且被正确限制，更新源不清空旧烟。
- 捕获分辨率 256/512 的发射率基本一致，源网格关闭 CPU Read/Write 后仍能捕获。
- Reset 清空密度，禁用组件释放资源，原模型保持开启。

GPU 读回仅用于上述编辑器验证。报告在 `Library/VolumeSmoke3D-validation.txt`，正面/侧面/背面预览在 `Preview/`。
