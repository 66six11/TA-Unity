# SDF 描边性能测试（2026-10-30）

环境：Unity 6000.5.7f1，NVIDIA GeForce RTX 4060 Laptop GPU，Direct3D12，13th Gen Intel(R) Core(TM) i7-13700H。

## 方法

Unity 编辑器离屏渲染，ARGB32、1×MSAA；每组预热30次、采样90次，共17组。CPU为单次 SubmitRenderRequest 的墙钟耗时，不是整帧耗时；GPU为 SDF 各 Pass 的 Recorder 时间戳均值之和，不包含场景其他渲染，也不是完整 GPU 帧耗时。未使用同步 GPU 等待。测试期间启用 Profiler；编辑器和硬件调度可能影响结果，不等同于打包运行。每个活跃 GPU Marker 各有90个有效样本；关闭 Feature 时 SDF GPU Marker 为0。

基础 SDF组关闭虚线、尖刺、纸纹与外围线纹；虚线组仅开虚线；尖刺组开虚线与尖刺；Full 全部开启。开关只改变参数，不剔除公共 SDF/投影归约 Pass，也不保证 Shader 编译器跳过所有关闭功能的计算。GUI不包含在CPU提交计时内。

## 结论与边界

主要开销在全分辨率 JFA传播，约占全效果 GPU Pass时间的80%～85%。当前基础SDF与尖刺/全效果之间的GPU差异较小，不能将开关差值直接解读为独立功能成本；公共Pass和部分Shader计算仍然存在。

1080p转动组：预热后每次采样转动0.3°，共约27°；其GPU时间与静态全效果接近，不支持“转动视角显著增加GPU总耗时”的判断。本测试不衡量视觉稳定性，边缘伪尖刺仍属于坐标/采样问题。

1440p的CPU P95波动较大；1080p关闭Feature的CPU中位数首末也有漂移，应避免对0.01ms级别差异作因果判断。不能用这些数据直接计算游戏整体FPS。

优先优化方向（尚未实施）：降低SDF计算分辨率并保持最终合成全分辨率；在满足描边最大距离的条件下评估有限范围传播；用GPU捕获确认Shader中关闭功能是否仍执行。任何优化均需检查细轮廓、尖角、最近边界坐标精度和稳定性。

## 复测

打开 SdfOutlineDemo，执行 Tools > TA > SDF Outline > Run Performance Test。状态输出 Library/SdfPerformance-status.txt，原始结果 Library/SdfPerformance.json。测试结束会恢复相机位置、启用状态、效果参数与Profiler状态。测试过程中请勿修改场景或参数。

固定参数：描边5px；虚线20段、保留0.65；尖刺48个、高18px、外移3px、随机度0.65、种子17；纸纹强度0.45；外围线纹间距9px、线宽1px、范围64px。
